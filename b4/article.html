Windows 11 저장 공간 센스 설정 방법: C드라이브 임시 파일 자동 정리와 정리 권장 사항

C드라이브 막대가 빨간색으로 바뀌었다면 Windows가 이미 "디스크 공간 부족 상태"라고 판단한 겁니다. Microsoft 지원 문서에 따르면 저장 공간이 부족하면 PC가 느려지고 Windows 업데이트 설치에 문제가 생길 수 있어요. 이럴 때 손으로 파일을 찾아 지우기 전에 켜 둘 기능이 저장 공간 센스입니다.

저장 공간 센스는 임시 파일과 휴지통 항목처럼 필요 없는 것을 자동으로 지워 주는 Windows 11 기본 기능이고, 기본값은 꺼짐입니다. 아래는 설정 앱 메뉴 이름 그대로 켜는 순서, 휴지통·다운로드·OneDrive 기간을 고르는 기준, 그리고 정리 후에도 공간 부족 오류가 날 때 순서대로 해 볼 조치를 정리한 것입니다. 메뉴 경로와 설명은 10월 9일 Microsoft 지원 문서 기준이에요. 드롭다운에 보이는 선택지 이름은 Windows 버전에 따라 조금 다를 수 있습니다.

정리 전에 남은 공간과 부족 상태 먼저 보기

먼저 지금 얼마나 남았는지 숫자로 봐 둬야 정리 효과를 비교할 수 있습니다. 작업 표시줄에서 파일 탐색기를 열고 왼쪽에서 내 PC를 누르면 "장치 및 드라이브"에 드라이브별 사용 가능한 공간이 나와요. 이 숫자를 메모해 두세요.

두 번째로 볼 곳은 시작 → 설정 → 시스템 → 저장소입니다. 맨 위 용량 막대가 빨간색이면 디스크 부족 상태예요. Microsoft 문서는 부족 여부가 디스크 크기와 최소 작동 임계값에 따라 달라진다고 설명합니다. 같은 20GB 여유라도 드라이브 크기에 따라 빨간색일 수도, 아닐 수도 있다는 뜻이에요.

저장소 화면 아래쪽 "디스크 사용량"에는 앱, 임시 파일, 문서, 사진 같은 범주별 용량이 막대로 나옵니다. 어떤 범주가 큰지 보고 나면 이후 단계에서 무엇을 먼저 손댈지 정할 수 있어요.

"임시 파일" 범주를 누르면 휴지통, 다운로드, Windows 업데이트 정리 파일처럼 세부 항목이 체크박스와 용량으로 펼쳐집니다. 여기 표시된 숫자가 곧 지웠을 때 돌아오는 공간이라, 아래 계산 예시에 그대로 넣어 쓰면 돼요.

확인할 곳메뉴 경로볼 것
남은 공간파일 탐색기 → 내 PC드라이브별 사용 가능 용량
부족 상태설정 → 시스템 → 저장소용량 막대가 빨간색인지
큰 범주저장소 → 디스크 사용량임시 파일·앱·문서 크기

한 가지 알아 둘 점은 저장 공간 센스가 시스템 드라이브(보통 C:)에서만 작동한다는 것입니다. D드라이브 같은 다른 드라이브를 정리하려면 설정 → 시스템 → 저장소 → 고급 저장소 설정 → 다른 드라이브에서 사용되는 저장소로 따로 들어가야 해요.

저장 공간 센스 켜고 실행 주기 정하는 순서

켜는 것 자체는 스위치 하나지만, 그 안의 세부 설정까지 정해 둬야 원하는 대로 돌아갑니다. Microsoft 안내 순서대로 따라가면 이렇습니다.

  1. 시작 → 설정 → 시스템 → 저장소로 이동합니다.
  2. "저장 공간 센스" 스위치를 켜기로 바꿉니다.
  3. 스위치 옆 "저장 공간 센스" 글자를 눌러 세부 설정 화면으로 들어갑니다.
  4. "저장 공간 센스 실행" 아래 드롭다운에서 실행 빈도를 고릅니다. 이 빈도는 PC가 온라인이고 로그인돼 있을 때 기준입니다.
  5. "임시 파일 정리" 아래에서 휴지통과 다운로드 폴더의 삭제 기간을 고릅니다(다음 단락에서 기준 설명).
  6. OneDrive에 로그인돼 있다면 "로컬에서 사용 가능한 클라우드 콘텐츠" 기간도 고릅니다.

설정은 사용자별로 적용됩니다. 한 PC를 가족이 각자 계정으로 쓴다면 내 계정에서 켠 저장 공간 센스는 내 휴지통과 다운로드 폴더에만 작동하고, 다른 사람은 자기 계정에서 따로 정해야 해요. 또 로그인한 상태로 10분 이상 온라인이어야 실행되니, 잠깐 켰다 끄는 PC라면 실행 시점이 늦어질 수 있습니다.

스위치만 켜고 세부 설정을 건드리지 않으면 디스크가 부족할 때 실행돼 불필요한 임시 파일을 지우는 기본 동작만 합니다. 휴지통 항목은 일정 기간이 지나면 지워지지만, 다운로드 폴더와 OneDrive 파일은 따로 지정하지 않는 한 그대로 남아요. 다운로드 폴더를 자주 비우지 않는 사람이라면 이 차이가 체감 용량을 크게 가릅니다.

참고로 스위치를 직접 켠 적이 없는데 켜져 있다면 이상한 일이 아닙니다. Microsoft 문서에 따르면 기본값은 꺼짐이지만 디스크 공간이 부족해지면 Windows가 저장 공간 센스를 자동으로 켤 수 있어요. 이 경우에도 세부 설정은 한 번 들어가서 내 기준으로 바꿔 두는 편이 좋습니다.

휴지통·다운로드·OneDrive 기간 고르는 기준

세부 설정의 세 항목은 지우는 대상과 되돌릴 수 있는지가 서로 다릅니다. 이 차이를 알고 기간을 고르면 실수로 필요한 파일을 잃을 일이 줄어요.

항목하는 일되돌리기
휴지통 기간기간이 지난 휴지통 파일 삭제삭제 후 복원 어려움
다운로드 폴더 기간그 기간 이상 열지 않은 파일 삭제삭제됨, 미리 옮겨야 함
클라우드 콘텐츠 기간안 연 파일을 온라인 전용으로파일은 그대로, 다시 열면 내려받음

가장 조심할 것은 다운로드 폴더입니다. 기준이 "만든 날"이 아니라 "마지막으로 연 날"이라, 설치 파일이나 받아 둔 서류를 다운로드 폴더에 보관하는 습관이 있다면 기간이 지나면서 사라질 수 있어요. 남겨야 할 파일을 문서 폴더로 옮긴 뒤에 이 기간을 켜는 순서가 안전합니다. 휴지통 기간은 반대로 짧게 잡아도 부담이 적은 편이에요. 이미 한 번 지우기로 결정한 파일이니, 복원할 여유를 며칠만 남겨 두면 됩니다.

OneDrive 항목은 지우는 기능이 아닙니다. Microsoft 문서는 이 설정이 파일을 영구 삭제하지 않고, 공간과 네트워크가 있으면 다시 로컬에서 쓸 수 있다고 적었어요. Windows 11 버전 22H2부터 기본값은 30일 이상 열지 않은 파일을 온라인 전용으로 바꾸는 것이고, "이 디바이스에서 항상 유지"로 표시한 파일은 대상에서 빠집니다.

정리 목표 용량을 숫자로 잡는 법

  1. 목표 여유 공간 − 현재 여유 공간 = 확보할 용량 (예: 40GB − 12GB = 28GB)
  2. 저장소 화면 표시값 합산: 임시 파일 6GB + 휴지통 4GB + 다운로드 15GB = 25GB
  3. 부족분: 28GB − 25GB = 3GB는 개인 파일 이동이나 OneDrive 온라인 전용으로 채우기

위 숫자는 계산 방법을 보여 주는 예시이고, 실제 값은 내 PC 저장소 화면에 표시된 용량을 넣으면 됩니다. 목표 여유 공간을 미리 정해 두면 어디까지 지울지 판단하기가 쉬워요.

정리 권장 사항으로 한 번에 비우기

저장 공간 센스를 계속 켜 두고 싶지 않다면 필요할 때만 "정리 권장 사항"을 쓰면 됩니다. Windows가 지울 만한 파일을 범주별로 골라 주고, 지웠을 때 확보되는 용량을 함께 보여 줘요.

  1. 시작 → 설정 → 시스템 → 저장소 → 정리 권장 사항을 선택합니다.
  2. 임시 파일, 대용량 또는 사용되지 않는 파일, 클라우드에 동기화된 파일, 사용되지 않는 앱 범주를 하나씩 펼쳐 봅니다.
  3. 지울 항목에 체크하고 범주마다 있는 정리 단추를 누릅니다.

"대용량 또는 사용되지 않는 파일"에는 직접 만든 영상이나 백업 파일이 섞여 나올 수 있어서, 이름을 하나씩 보고 체크하는 게 좋습니다. 반면 임시 파일 범주는 대부분 지워도 되는 항목이라 확보 용량이 큰 경우가 많아요.

"이전 Windows 설치"는 지우면 되돌릴 수 없습니다

Windows를 업그레이드한 지 10일이 안 됐다면 이전 버전 Windows가 삭제 가능한 시스템 파일로 나옵니다. 지우면 Windows.old 폴더가 사라져 이전 버전으로 되돌리는 옵션도 없어집니다. 새 버전이 안정적인지 며칠 써 본 뒤 지우세요.

Windows.old를 직접 지우는 경로도 문서에 있습니다. 설정 → 시스템 → 저장소 → 임시 파일에서 "이전 Windows 설치"에 체크하고 파일 제거를 누르면 돼요. 큰 기능 업데이트 직후 C드라이브가 갑자기 줄었다면 이 항목이 원인인 경우가 많습니다.

예전부터 쓰던 디스크 정리 도구도 그대로 있습니다. 작업 표시줄 검색 상자에 "디스크 정리"를 입력해 열고 드라이브를 고르면 되는데, Downloaded Program Files, Temporary Internet Files, Thumbnails가 기본으로 체크돼 있어요. 시스템 파일 정리를 한 번 더 누르면 업데이트 잔여 파일 같은 시스템 항목까지 계산해 보여 주니, 정리 권장 사항과 결과를 비교해 볼 때 쓰기 좋습니다.

정리했는데도 공간 부족 오류가 날 때

정리 권장 사항까지 썼는데도 공간 부족 오류가 계속된다면, Microsoft 문서는 임시 폴더가 Microsoft Store 앱 패키지(.appx) 파일로 빠르게 차는 경우를 짚습니다. 이때는 아래 순서로 조치해요.

  1. 설정 → 시스템 → 문제 해결 → 기타 문제 해결사에서 "Windows 스토어 앱" 옆 실행을 누릅니다.
  2. Windows 로고 키 + R로 실행 창을 열고 wsreset.exe를 입력한 뒤 확인을 누릅니다. 빈 명령 창이 열렸다가 약 10초 뒤 닫히고 Microsoft Store가 열리면 캐시 정리가 끝난 것입니다.
  3. 같은 기타 문제 해결사 화면에서 "Windows 업데이트" 옆 실행을 누릅니다.
  4. PC를 다시 시작하고 오류가 계속되는지 봅니다.

업데이트 설치 공간이 잠깐 모자란 상황이라면 OS 드라이브 압축도 선택지입니다. 파일 탐색기 → 내 PC → C드라이브 우클릭 → 속성 → 일반 탭에서 "이 드라이브를 압축하여 디스크 공간 절약"을 체크하고 적용을 누르면 돼요. Microsoft는 이 작업이 내용을 지우지 않고 파일을 열고 저장하는 데도 문제가 없다고 설명하며, 업데이트 뒤 체크를 해제해 언제든 압축을 풀 수 있습니다.

원인을 모르게 용량이 계속 줄어든다면 악성 코드도 의심해 볼 만합니다. 문서는 바이러스나 맬웨어가 시스템 파일을 손상시켜 상당한 공간을 차지할 수 있다며, Windows 보안 같은 백신으로 검사하라고 안내해요. 점검 범위를 넓히고 싶다면 한국인터넷진흥원(KISA) 보호나라의 내 PC 돌보미에서 Windows 11 PC용 자가 보안진단 도구를 받아 보안 설정까지 함께 점검할 수 있습니다. 그래도 업데이트가 안 될 정도로 공간이 없으면 USB 드라이브 같은 외부 저장 장치를 연결해 업데이트를 마치는 방법도 있습니다.

순서를 정리하면 가벼운 것부터입니다. 스토어 캐시와 문제 해결사는 파일을 지우지 않으니 먼저 해 보고, 드라이브 압축은 업데이트처럼 일시적으로 공간이 필요할 때, 외부 저장 장치는 마지막 수단으로 남겨 두면 됩니다.

새 파일 저장 위치를 다른 드라이브로 돌리기

정리는 한 번으로 끝나지 않으니 새로 쌓일 파일의 위치를 바꿔 두면 다음 정리 주기가 길어집니다. D드라이브나 외장 드라이브가 있다면 설정 → 시스템 → 저장소 → 고급 저장소 설정 → 새 콘텐츠가 저장되는 위치에서 콘텐츠 종류별로 드라이브를 고를 수 있어요. 원하는 드라이브가 목록에 없으면 PC에 연결돼 있는지부터 봅니다.

이미 쌓인 큰 파일은 파일 탐색기에서 찾아 옮깁니다. 비디오·음악·사진·다운로드 폴더에 큰 파일이 몰려 있는 경우가 많고, 폴더를 연 뒤 보기 → 세부 정보로 바꾸고 빈 곳을 우클릭해 정렬 기준 → 크기를 고르면 가장 큰 파일이 맨 위로 올라와요. 파일을 지웠다면 휴지통을 비워야 실제 공간이 돌아옵니다.

자주 열지 않지만 남겨야 할 사진이나 영상은 USB 드라이브나 SD 카드로 옮기는 방법을 문서가 권합니다. 외장 장치를 연결한 뒤 파일 탐색기에서 파일을 고르고 홈 → 이동 → 위치 선택으로 외장 드라이브를 지정하면 돼요. 장치가 연결돼 있는 동안은 파일을 그대로 쓸 수 있고 PC 공간은 차지하지 않습니다.

상황별로 정리하면 이렇습니다. OneDrive를 쓰는 노트북이라면 클라우드 콘텐츠 기간을 켜 두는 것만으로 사진·문서가 온라인 전용으로 바뀌며 공간이 생겨요. 드라이브가 두 개인 데스크톱이라면 새 콘텐츠 저장 위치를 D드라이브로 돌리고, C드라이브는 저장 공간 센스로 임시 파일만 관리하는 구성이 손이 덜 갑니다.
