안드로이드 앱 언어 변경 방법: 설정에서 앱마다 바꾸는 순서

안드로이드에서는 기기 전체 언어를 바꾸지 않고 일부 앱의 표시 언어만 따로 변경할 수 있습니다. Google 공식 안내의 기본 경로는 설정 앱에서 ‘시스템 → 언어 → 앱 언어’로 들어가 앱을 고른 다음 지원 언어를 선택하는 방식입니다. 다만 이 기능은 Android 14 이상에서 제공되는 단계가 있고, 개발자가 앱 언어 기능을 지원한 앱만 목록에 나타납니다. 메뉴가 보이지 않는다고 해서 휴대전화 고장으로 단정할 필요는 없습니다.

앱 언어 변경 경로를 표로 확인하세요

순서메뉴할 일
1설정시스템으로 이동
2언어앱 언어 선택
3앱 선택지원 언어 지정

제조사별 Android 화면에서는 메뉴 이름이나 위치가 조금 다를 수 있습니다. 아래 순서를 찾기 어렵다면 설정 앱 검색창에서 ‘앱 언어’ 또는 ‘언어’를 검색해 보세요. 검색 결과가 없으면 Android 버전과 앱의 지원 여부를 먼저 확인해야 합니다.

특정 앱의 언어를 어떻게 바꾸나요?

  1. 휴대전화에서 설정 앱을 엽니다.
  2. 시스템을 누른 뒤 언어를 선택합니다.
  3. 앱 언어를 누르고 변경할 앱을 선택합니다.
  4. 목록에서 사용할 언어를 선택합니다.

앱 목록에는 언어 선택 기능을 지원하도록 개발자가 설정한 앱만 표시됩니다. 앱을 선택한 뒤 보이는 언어 목록은 해당 앱이 제공하는 범위이므로, 휴대전화에 언어가 설치되어 있다는 이유만으로 모든 앱에서 선택할 수 있는 것은 아닙니다. 앱이 시스템 기본값을 따르도록 설정되어 있다면 목록에서 지원하는 언어 중 첫 번째 언어를 사용할 수 있다고 Google은 안내합니다.

변경 후 앱 화면이 즉시 바뀌지 않는다면 앱을 완전히 닫았다가 다시 여세요. 계정 안에서만 언어를 바꾸도록 만든 앱도 있으므로, 시스템의 앱 언어 목록에 없을 때는 해당 앱의 자체 설정 메뉴도 확인해야 합니다.

앱 언어가 바뀌지 않을 때 무엇을 확인하나요?

언어를 선택했는데 화면이 그대로라면 Google이 안내하는 순서대로 앱을 다시 시작하고, 기기가 네트워크에 연결되어 있는지 확인하세요. 인터넷에 연결되지 않은 상태에서 앱 언어를 바꾸면 업데이트되지 않을 수 있습니다. 앱도 최신 버전으로 업데이트합니다. 최신 지원 언어 목록이 앱 업데이트로 달라질 수 있기 때문입니다.

  • 앱을 완전히 닫았다가 다시 엽니다.
  • 기기가 Wi-Fi나 모바일 네트워크에 연결되어 있는지 확인합니다.
  • Play 스토어 등에서 앱을 최신 버전으로 업데이트합니다.
  • 필요하면 기기 언어 설정에서 원하는 언어를 보조 언어로 추가합니다.
  • 몇 분 뒤 설정 앱을 다시 열어 앱 언어를 다시 선택합니다.

그래도 바뀌지 않는다면 해당 앱의 지원 언어 목록이 실제 기능과 다르게 표시되는 경우도 있습니다. 앱 데이터 지우기는 앱을 초기화할 수 있으므로, 로그인 정보나 저장 데이터가 사라질 수 있는지 앱 안내를 먼저 확인한 뒤 마지막 수단으로 판단하세요.

앱 언어와 기기 언어는 어떻게 다른가요?

앱 언어는 선택한 앱의 표시 언어만 바꾸는 기능입니다. 메시지나 설정 같은 기기 전체 메뉴와 다른 앱까지 한꺼번에 바꾸고 싶다면 시스템 언어 설정을 조정해야 합니다. 시스템 언어를 바꾼다고 해서 모든 앱이 같은 언어로 바뀌는 것도 아닙니다. 앱이 해당 언어를 지원하는지와 앱이 시스템 언어를 따르는 방식에 따라 화면이 달라질 수 있습니다.

예를 들어 지도 앱만 다른 언어로 보고 싶다면 앱 언어 메뉴에서 해당 앱을 선택하면 되고, 휴대전화의 날짜·설정 메뉴까지 바꾸려면 기기 언어를 조정해야 합니다. 두 기능을 구분하면 원하지 않는 앱까지 한꺼번에 바뀌는 일을 피할 수 있습니다.

지역 설정도 따로 바꿀 수 있나요?

Google 안내에는 Android 14 이상에서 ‘시스템 → 언어 → 지역 설정’으로 들어가 지역 관련 표시 방식을 정할 수 있다고 나옵니다. 지역 설정에서는 섭씨·화씨 같은 온도 단위, 한 주의 시작 요일, 일부 언어에서 사용하는 번호 환경설정을 바꿀 수 있습니다. 이는 앱의 번역 언어를 바꾸는 메뉴와는 별도의 기능입니다.

지역 설정의 기본값은 시스템 및 앱 언어 설정을 기준으로 정해질 수 있습니다. 따라서 영어 앱을 사용하면서도 온도 단위나 주 시작 요일만 원하는 방식으로 조정할 수 있습니다. 지역 설정 메뉴가 보이지 않으면 Android 버전과 제조사별 메뉴 구성을 확인하세요. Google도 맞춤 Android 버전에서 안내된 단계가 해결되지 않으면 기기 제조업체에 문의하라고 설명합니다.

지역 설정을 바꾸기 전에 어떤 표시만 바꾸려는지 구분해 두면 좋습니다. 앱의 메뉴와 버튼 번역이 목적이면 앱 언어를 선택하고, 날씨의 섭씨·화씨 표시나 달력의 주 시작 요일이 목적이면 지역 설정을 조정합니다. 두 설정을 한꺼번에 바꿀 필요는 없으며, 변경 뒤에는 해당 앱을 다시 열어 표시가 원하는 방식인지 확인하세요.

Android 14 이상이라도 제조사가 화면 구성을 바꿔 메뉴 이름이 다르게 보일 수 있습니다. 이때는 설정 검색으로 ‘지역 설정’을 찾아보고, 그래도 항목이 없으면 사용 중인 Android 버전과 제조사 지원 문서를 확인하세요. Google 안내 단계와 실제 화면이 다를 때 제조업체 문의가 필요한 이유도 여기에 있습니다.

지역 설정을 바꾼 뒤 일부 앱의 표시가 달라지지 않는다면 앱이 해당 지역 설정을 읽도록 개발되었는지도 확인해야 합니다. Google 안내는 지역 설정을 지원하는 Android 기능의 범위를 설명하는 것이므로, 모든 앱의 화면이 같은 방식으로 바뀐다고 보기는 어렵습니다.

자주 묻는 질문

Q. 모든 앱의 언어를 바꿀 수 있나요?

아닙니다. 개발자가 앱 언어 기능을 지원한 앱만 앱 목록에 나타납니다. 목록에 없는 앱은 앱 자체 설정이나 개발자가 제공하는 방법을 확인해야 합니다.

Q. 앱 언어를 바꿨는데 그대로예요.

앱을 다시 시작하고 네트워크 연결과 최신 버전 여부를 확인하세요. Google은 보조 언어를 추가한 뒤 몇 분 후 앱 언어를 다시 전환하는 방법도 안내합니다.

Q. 앱마다 지원하는 언어가 다른가요?

그렇습니다. 앱 목록에 표시되더라도 앱마다 선택 가능한 언어가 다를 수 있습니다. 최신 지원 언어 목록을 보려면 앱을 업데이트하세요.

Q. 지역 설정을 바꾸면 앱 번역도 바뀌나요?

지역 설정은 온도 단위, 주 시작 요일, 번호 환경설정 등을 정하는 기능입니다. 앱의 표시 언어를 바꾸려면 앱 언어 메뉴에서 언어를 별도로 선택해야 합니다.
