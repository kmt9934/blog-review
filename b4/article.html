윈도우 캡처 도구 사용법: 영역 캡처·저장·스크린샷 폴더 찾기

Windows 11·10에서 화면 일부나 창, 전체 화면을 이미지로 남기려면 기본 앱인 캡처 도구를 사용할 수 있습니다. 빠른 캡처는 Windows 로고 키 + Shift + S를 눌러 시작하고, 캡처 뒤에는 미리보기 알림을 열어 주석을 달거나 저장합니다. 자동 저장된 파일은 스크린샷 폴더에서 찾을 수 있지만, 자동 저장 설정은 Windows 버전과 사용자 설정에 따라 확인해야 합니다.

작업별 빠른 방법

  • 빠른 캡처: Windows 키 + Shift + S
  • 창·사각형·자유형·전체 화면: 캡처 도구에서 모드 선택
  • 파일 저장: 캡처 후 알림을 열어 저장, 또는 Ctrl + S
  • 영상 녹화: Windows 키 + Shift + R

캡처 도구는 어떻게 열고 어떤 캡처를 고르나요?

시작 메뉴를 열고 검색창에 ‘캡처 도구’를 입력한 다음 앱을 선택하면 됩니다. 키보드로 빠르게 시작하려면 Windows 로고 키 + Shift + S를 누릅니다. Microsoft 지원은 이 바로가기가 캡처 오버레이를 열어 이미지 스냅샷을 만들 수 있게 한다고 안내합니다.

캡처 도구에서는 자유형, 사각형, 창, 전체 화면 캡처를 선택할 수 있습니다. 자유형은 원하는 모양으로 영역을 둘러싸고, 사각형은 필요한 범위를 드래그해 지정합니다. 창 캡처는 대화상자나 앱 창처럼 특정 창을 남길 때 편하고, 전체 화면은 화면 전체 내용을 한 번에 저장할 때 사용합니다.

사용 목적에 따라 캡처 유형을 먼저 정하면 불필요한 개인정보나 다른 창이 이미지에 함께 찍히는 일을 줄일 수 있어요. 오류 메시지만 공유하려면 오류창 캡처를 선택하고, 메뉴 동작을 설명하려면 메뉴가 열린 상태에서 창 또는 영역을 캡처합니다. 캡처 전 알림이나 계정 이름처럼 공유하면 안 되는 정보가 화면에 있는지 확인하세요.

앱을 직접 연 경우에는 캡처 모드와 새로 만들기를 선택한 뒤 화면에서 영역을 지정합니다. 바로가기로 시작한 경우 화면이 어두워지고 포인터가 캡처 선택 모드로 바뀝니다. 선택을 취소하거나 다시 찍어야 하면 캡처 도구 창으로 돌아가 새 캡처를 시작하세요.

캡처한 이미지에 표시하고 저장하려면 어떻게 하나요?

캡처를 마치면 이미지가 캡처 도구 창으로 복사되고, 알림을 눌러 편집 화면을 열 수 있습니다. 펜이나 형광펜으로 필요한 부분을 표시하고, 지우개로 주석을 지우거나 이미지 자르기로 불필요한 주변을 정리합니다. Microsoft 지원은 캡처 후 텍스트 작업 기능으로 이미지에서 글자를 복사하는 OCR도 제공한다고 안내합니다.

파일로 남기려면 편집 창의 저장 버튼을 누르거나 Ctrl + S를 사용해 위치와 파일명을 지정합니다. Microsoft는 캡처가 스크린샷 폴더에 자동 저장된다고 안내하지만, 자동 저장 기능과 기본 폴더 위치는 설정에서 바꿀 수 있습니다. 따라서 파일이 보이지 않으면 먼저 캡처 도구 설정과 저장한 위치를 확인하세요.

클립보드에만 복사해 둔 캡처는 다른 앱에 붙여넣을 수 있지만, 나중에 다시 찾으려면 별도 파일로 저장해야 합니다. 알림을 닫았더라도 클립보드 기록이나 캡처 도구의 최근 화면에서 복구할 수 있다고 단정하기 어렵습니다. 중요한 이미지는 편집을 마친 즉시 저장하고, 저장 후에는 파일을 열어 이미지가 실제로 생성됐는지 확인하는 습관이 좋습니다.

저장 형식과 위치는 제출하거나 공유할 곳의 요구에 맞춥니다. 문서에 바로 넣을 이미지라면 PNG 등 일반 이미지 형식으로 저장하고, 파일 이름에는 날짜와 화면 내용을 알아볼 수 있는 단어를 넣어 두면 나중에 찾기 쉽습니다. 개인 정보가 포함된 캡처를 외부에 공유할 때는 주석이나 자르기로 해당 부분을 가리고, 원본 파일에도 민감정보가 남아 있지 않은지 확인하세요.

스크린샷 파일은 어디에 저장되고 못 찾으면 어떻게 하나요?

캡처 도구에서 자동 저장이 켜져 있으면 스크린샷 폴더에 저장됩니다. Microsoft 지원은 자동 저장 동작이나 기본 스크린샷 폴더를 바꾸려면 캡처 도구의 자세히 보기 메뉴에서 설정을 열도록 안내합니다. 장치에서 자동 저장 설정이 꺼져 있을 수 있으므로, 저장 파일이 없을 때는 해당 설정을 먼저 확인하고 캡처를 다시 저장해 보세요.

직접 저장을 선택했다면 저장 대화상자에 지정한 폴더를 확인합니다. 파일 탐색기에서 ‘스크린샷’ 또는 파일명 일부를 검색하고, 최근 파일 정렬로 방금 저장한 이미지가 있는지 볼 수 있습니다. 파일명이 기억나지 않아도 저장한 날짜와 이미지 형식으로 범위를 좁히면 찾기 쉬워요.

캡처가 클립보드에만 남아 있을 수 있습니다. 메신저나 문서 편집기에 붙여넣어 보이는 이미지를 확인한 뒤, 그 앱에서 다시 파일로 저장할 수 있습니다. 단, 클립보드에 있는 이미지가 계속 보관된다고 보장할 수 없으므로 필요한 경우 새 캡처를 찍고 캡처 도구에서 바로 저장하세요.

저장 폴더를 바꾸었다면 동기화 서비스나 회사 정책으로 실제 위치가 달라질 수도 있습니다. 스크린샷 폴더가 OneDrive 등 다른 위치로 연결되었는지, 캡처 도구 설정에서 자동 저장 경로가 바뀌었는지 확인하세요. 저장 버튼을 눌렀는데 오류가 나면 폴더 접근 권한과 디스크 여유 공간도 점검합니다.

저장 안 된 것처럼 보일 때

먼저 캡처 알림을 눌러 편집 창을 열고 Ctrl+S로 저장 위치를 직접 선택하세요. 자동 저장 경로는 설정에서 확인하고, 파일 탐색기에서 저장한 날짜로 검색합니다.

메뉴 캡처와 화면 녹화는 어떻게 하나요?

메뉴를 펼친 상태로 캡처하려면 지연 캡처를 활용할 수 있습니다. Microsoft 지원은 캡처 도구에서 지연 시간을 선택한 뒤 새 캡처를 시작하면 카운트다운 중 메뉴를 열 수 있다고 안내합니다. 지연 캡처는 드롭다운이나 마우스를 올려야 나타나는 메뉴를 남길 때 유용합니다. 화면이나 앱에 따라 표시 시간이 짧을 수 있으므로 캡처 전에 메뉴를 열 순서를 연습해 보세요.

캡처 도구는 정지 이미지뿐 아니라 화면 일부를 비디오로 녹화하는 기능도 제공합니다. 빠르게 녹화를 시작하려면 Windows 로고 키 + Shift + R을 누르고, 녹화할 영역을 선택한 다음 시작을 누릅니다. 녹화를 마치면 중지를 선택하고 영상을 저장합니다. 음성이나 자막이 필요하다면 Microsoft가 안내하는 Clipchamp 편집 기능을 이용할 수 있습니다.

영상으로 단계별 동작을 보여주는 편이 좋은지, 한 장의 캡처에 표시하는 편이 좋은지 먼저 생각해 보세요. 비밀번호 입력이나 개인 메시지처럼 민감한 정보가 화면에 나타날 수 있다면 녹화하지 말고, 공유 전 영상의 앞뒤 구간을 다시 확인해야 합니다. 화면 녹화 기능과 편집 옵션은 Windows 버전에 따라 보이는 방식이 달라질 수 있습니다.

캡처 도구를 자주 쓴다면 시작 메뉴 검색에서 앱을 찾아 작업 표시줄에 고정할 수 있습니다. 바로가기 키는 앱이 실행 중이 아니어도 캡처 오버레이를 열 수 있으므로 급할 때 유용합니다. 단축키가 동작하지 않으면 키보드 설정, 다른 앱의 단축키 충돌, 캡처 도구 앱 상태를 확인하고 시작 메뉴에서 직접 실행하세요.

Windows 캡처 도구 자주 묻는 질문

Q. 캡처 도구를 빠르게 여는 키는 무엇인가요?
이미지 캡처는 Windows 로고 키와 Shift와 S를 함께 누르면 오버레이가 열립니다.

Q. 저장된 스크린샷 폴더를 바꿀 수 있나요?
캡처 도구의 자세히 보기 메뉴에서 설정을 열어 자동 저장 동작과 기본 폴더를 확인할 수 있습니다.

Q. 드롭다운 메뉴를 캡처하려면 어떻게 하나요?
지연 캡처를 선택하고 카운트다운 중 메뉴를 펼친 뒤 원하는 영역을 캡처합니다.

Q. 화면을 동영상으로 녹화할 수 있나요?
캡처 도구의 비디오 캡처 기능이나 Windows 키+Shift+R 바로가기를 사용할 수 있습니다.
