Windows 11 클립보드 기록·기기 간 동기화 설정과 기록 지우기

Windows 11에서 복사한 여러 항목을 다시 쓰려면 Windows 키+V로 클립보드 기록을 열고, 설정의 시스템 > 클립보드에서 기록을 켭니다. 기기 간 동기화는 같은 Microsoft 또는 회사 계정으로 로그인한 Windows 기기에서 별도 설정해야 해요. 기록을 지울 때는 고정한 항목은 남을 수 있으므로, 민감한 내용을 복사했다면 핀 고정 여부도 확인하는 편이 안전합니다.

Microsoft Phone Link에서 Android와 PC 간 복사·붙여넣기를 쓰려면 PC 앱 설정의 기능 메뉴에서 교차 기기 복사·붙여넣기를 활성화해야 합니다. 모든 Android 기기에서 동일하게 지원되는 것은 아니며, Microsoft 지원 목록에 해당 기기 계열이 포함되는지 먼저 확인합니다.

클립보드 기록을 처음 켜고 열려면 어떻게 하나요?

키보드에서 Windows 로고 키와 V를 함께 누르면 클립보드 기록 창이 열립니다. 처음 사용하는 경우 화면에 기록을 켜는 안내가 나타나며, 켜기를 선택하면 이후 복사한 항목을 기록 창에서 다시 고를 수 있습니다. 기능이 비활성화되어 있으면 Ctrl+C와 Ctrl+V의 기본 복사·붙여넣기는 가능해도 이전 항목 목록은 보이지 않습니다.

설정 앱에서 직접 켜려면 시작 > 설정 > 시스템 > 클립보드로 이동한 뒤 클립보드 기록을 활성화합니다. 설정 화면 이름은 Windows 업데이트에 따라 약간 바뀔 수 있지만 시스템의 클립보드 항목에서 관련 스위치를 찾을 수 있어요. 이후 Windows 키+V를 누르고 목록에서 붙여 넣을 항목을 선택합니다.

Microsoft 지원 문서에 따르면 기록에는 텍스트와 이미지 등 복사 항목이 저장되며, 항목별 크기 제한은 4MB입니다. 클립보드 기록은 최대 25개 항목을 유지하고, 새 항목이 들어오면 고정하지 않은 오래된 항목이 자리를 내줄 수 있습니다. 큰 이미지나 지원되지 않는 형식이 기록에 보이지 않는다면 항목 크기와 형식을 먼저 확인합니다.

복사한 텍스트를 다른 Windows 기기와 동기화하려면?

각 Windows 기기에서 시작 > 설정 > 시스템 > 클립보드를 열고 기기 간 클립보드 기록 또는 동기화 스위치를 켭니다. 그 아래 자동 동기화 옵션을 선택하면 복사한 텍스트를 다른 기기에서도 사용할 수 있습니다. Microsoft 계정 또는 회사 계정에 연결된 기능이므로, 동기화할 기기들이 같은 계정으로 로그인되어 있어야 합니다.

자동 동기화 대신 필요한 항목만 수동으로 보내는 설정을 선택할 수도 있습니다. 이 경우 Windows 키+V로 기록을 연 다음 해당 항목의 동기화 아이콘을 선택해야 전송됩니다. 복사한 모든 문장이 다른 기기로 바로 올라가는 것을 원하지 않는다면 수동 동기화 방식이 더 통제하기 쉽습니다.

기기 사이에 텍스트가 나타나지 않는다면 양쪽 기기에서 동기화 스위치와 계정이 같은지 살펴보세요. 한쪽에서만 기능을 켜면 양방향 사용이 되지 않을 수 있습니다. 회사 관리 기기는 조직 정책으로 동기화가 제한될 수 있고, Microsoft 계정의 Windows 동기화 설정 상태도 영향을 줄 수 있습니다.

동기화 전 점검

  • 각 장치에서 동기화를 켭니다.
  • 양쪽 모두 같은 계정인지 확인합니다.
  • 민감한 정보는 자동 전송을 피합니다.

클립보드 기록에서 항목을 고정하거나 하나씩 지우려면?

자주 붙여 넣는 문구는 기록 목록에서 해당 항목의 더 보기 메뉴를 열고 핀 고정을 선택할 수 있습니다. 고정한 항목은 새 복사 내용이 쌓일 때 목록에서 밀려나지 않으며, PC를 다시 시작한 뒤에도 유지될 수 있습니다. 반복해서 쓰는 주소나 짧은 서식 문구처럼 민감하지 않은 내용에 적합합니다.

특정 항목만 지우려면 Windows 키+V를 눌러 목록을 열고 대상 항목 옆의 더 보기(…)를 선택한 다음 삭제를 누릅니다. 전체 기록은 남겨두면서 비밀번호나 개인 정보처럼 다시 보이면 곤란한 항목만 제거할 때 유용합니다. 고정 항목은 일반 기록과 별도로 관리해야 하므로 핀 표시도 함께 살펴보세요.

Windows 키+V 창은 현재 복사 기록을 확인하고 선택하는 공간입니다. 목록에서 항목을 누르면 현재 커서가 있는 앱으로 붙여 넣어집니다. 중요한 내용을 복사한 직후 다른 앱에서 붙여 넣을 때는 기록에 비슷한 문구가 여럿 저장되어 있지 않은지 선택 내용을 확인하고 진행합니다.

클립보드 기록을 모두 지우고 동기화 내용을 정리하려면?

전체 기록을 정리하는 경로는 두 가지입니다. 설정 > 시스템 > 클립보드의 클립보드 데이터 지우기 영역에서 지우기를 선택하거나, Windows 키+V를 눌러 기록 창의 모두 지우기를 선택합니다. Microsoft 안내는 이 작업으로 기기와 클라우드의 기록을 정리할 수 있다고 설명하지만, 핀으로 고정한 항목은 예외로 남을 수 있습니다.

기록을 비웠는데 특정 내용이 다시 보인다면 고정된 항목인지 확인합니다. 항목을 별도로 선택해 핀을 해제하거나 개별 삭제를 진행해야 할 수 있어요. 회사 기기에서 동기화가 관리되는 경우 조직 정책이나 계정 설정에 따라 동작이 달라질 수 있으므로, 기기에서 사라진 뒤 동기화 기기에서도 정리됐는지 각각 확인합니다.

PC를 재시작하면 고정되지 않은 기록은 비워지는 것이 Microsoft 지원 문서의 기본 설명입니다. 다만 다시 시작을 개인정보 정리의 유일한 방법으로 보지 말고, 민감한 복사 내용이 있다면 설정에서 직접 지우고 핀 고정된 기록까지 확인하는 것이 낫습니다. 계정 동기화를 사용한다면 다른 기기의 기록도 확인해야 합니다.

항목별 삭제Win+V > 항목 메뉴 > 삭제선택한 항목만 제거
전체 삭제설정 > 시스템 > 클립보드고정 항목은 별도 확인

Windows PC끼리 쓰는 클립보드 기록 동기화와 Android 휴대전화 연동은 별도 기능입니다. Microsoft Phone Link의 교차 기기 복사·붙여넣기는 지원되는 일부 Samsung·HONOR·OPPO·ASUS·vivo·Xiaomi 기기 또는 Surface Duo에서 사용할 수 있으며, PC의 Phone Link 설정에서 기능을 켜야 합니다. 일반 클립보드 동기화가 켜져 있어도 휴대전화에서 자동으로 작동한다고 가정하지 말고, 지원 기기와 앱 버전을 먼저 확인하세요.

KISA 보호나라는 2026년 1월 Microsoft 보안 업데이트 공지에서 Windows 11 23H2·24H2·25H2 보안 업데이트를 다뤘고, 같은 공지에 Windows Clipboard Server 권한 상승 취약점 항목도 포함했습니다. 이 공지는 클립보드 기능 설정법이 아니라 운영체제 보안 업데이트 안내이므로, 기록 동기화 설정과 별개로 Windows 업데이트도 유지해야 합니다. 클립보드에 인증 정보나 개인정보를 장기간 남기지 않는 사용 습관도 함께 적용하세요.

클립보드 기록이나 기기 간 동기화가 작동하지 않을 때?

Windows 키+V를 눌러도 기록이 비어 있으면 설정에서 클립보드 기록이 켜져 있는지 확인합니다. 기능을 처음 쓰는 PC에서는 단축키를 누른 뒤 켜기 동의를 해야 기록이 만들어집니다. 기능을 켜기 전에 복사한 항목이 과거 기록으로 자동 복원되는 것은 아니므로, 새 항목을 복사해 동작을 확인하세요.

다른 기기에서 동기화 항목이 보이지 않으면 각 장치에서 기기 간 동기화를 켰는지, 같은 Microsoft 또는 회사 계정을 쓰는지 확인합니다. 자동 동기화가 아니라 수동 동기화를 선택했다면 Windows 키+V 목록에서 해당 항목을 직접 동기화해야 합니다. 회사에서 관리하는 PC는 정책으로 기능이 꺼져 있을 수 있어 개인 설정만으로 바꾸지 못할 수 있습니다.

특정 파일만 기록되지 않는다면 Microsoft가 안내하는 항목별 4MB 제한과 지원 형식도 점검합니다. 클립보드 기록의 저장 개수는 최대 25개이며, 오래된 미고정 항목은 새 기록을 위해 제거될 수 있습니다. 이 한도에 가까울 때 자주 쓰는 항목만 고정하고 나머지는 필요할 때 다시 복사하면 목록 관리가 쉬워져요.

기기 간 클립보드 동기화는 보안상 설정을 끌 수도 있습니다. Microsoft Learn의 Privacy Policy CSP는 관리자가 교차 기기 클립보드 정책을 사용해 같은 Microsoft 계정 또는 Microsoft Entra 계정으로 로그인한 기기 사이의 공유를 허용하거나 차단할 수 있다고 설명합니다. 설정이 회색으로 잠겨 있거나 “조직에서 관리” 문구가 보이면 사용자가 임의로 우회하기보다 관리 담당자에게 정책을 문의해야 합니다.

자주 묻는 질문

클립보드 기록은 기본으로 켜져 있나요?

처음 사용할 때는 Windows 키+V를 누른 뒤 켜기 선택이 필요합니다. 설정 > 시스템 > 클립보드에서도 기록을 활성화할 수 있습니다.

기기 간 기록 동기화에는 무엇이 필요한가요?

각 Windows 기기에서 동기화를 켜고 동일한 Microsoft 또는 회사 계정으로 로그인해야 합니다. 자동 또는 수동 동기화 중 원하는 방식을 선택하세요.

기록을 모두 지우면 고정한 항목도 삭제되나요?

Microsoft 지원 문서는 전체 지우기에서도 핀 고정 항목은 예외라고 안내합니다. 고정된 항목은 목록에서 개별 확인 후 삭제합니다.

클립보드 기록에는 몇 개까지 저장되나요?

Microsoft 지원 문서 기준 최대 25개 항목이며, 각 항목은 4MB 제한이 있습니다. 고정하지 않은 오래된 항목은 새 복사 내용에 밀려 제거될 수 있습니다.
