안드로이드 앱 언어 변경 방법: 설정에서 앱마다 바꾸는 순서

안드로이드에서는 기기 전체 언어를 바꾸지 않고도 일부 앱의 언어만 따로 변경할 수 있습니다. Google 공식 안내 기준으로 설정 앱에서 ‘시스템 → 언어 → 앱 언어’로 들어간 뒤, 지원하는 앱을 선택해 언어를 바꾸면 됩니다. 이 기능은 Android 14 이상에서 일부 단계가 제공됩니다.

앱 언어 변경 경로를 표로 확인하세요

순서메뉴할 일
1설정시스템으로 이동
2언어앱 언어 선택
3앱 선택지원 언어 지정

특정 앱의 언어를 어떻게 바꾸나요?

  1. 휴대전화에서 설정 앱을 엽니다.
  2. 시스템을 누른 뒤 언어를 선택합니다.
  3. 앱 언어를 누르고 변경할 앱을 선택합니다.
  4. 목록에서 사용할 언어를 선택합니다.

앱 목록에는 이 기능을 지원하도록 개발자가 설정한 앱만 표시됩니다. 앱이 보이지 않는다면 휴대전화의 문제라기보다 해당 앱이 앱별 언어 기능을 지원하지 않는 경우일 수 있어요.

앱 언어가 바뀌지 않을 때 무엇을 확인하나요?

언어를 선택했는데 화면이 그대로라면 먼저 앱을 다시 시작하세요. Google은 네트워크 연결을 확인하고, 앱을 최신 버전으로 업데이트하라고 안내합니다. 일부 앱은 언어를 보조 언어로 추가한 뒤 다시 전환해야 할 수도 있습니다.

  • 앱을 완전히 닫았다가 다시 엽니다.
  • 기기가 네트워크에 연결되어 있는지 확인합니다.
  • 앱을 최신 버전으로 업데이트합니다.
  • 필요하면 기기 언어 설정에서 보조 언어를 추가한 뒤 다시 선택합니다.

앱 언어와 기기 언어는 어떻게 다른가요?

앱 언어는 선택한 앱의 표시 언어만 바꾸는 기능입니다. 기기 전체 메뉴와 다른 앱까지 한꺼번에 바꾸고 싶다면 시스템 언어 설정을 조정해야 합니다. 다만 앱별 언어는 지원 앱에서만 사용할 수 있고, 지원 언어 목록도 앱마다 다릅니다.

지역 설정도 따로 바꿀 수 있나요?

Google 안내에는 Android 14 이상에서 시스템 → 언어 → 지역 설정으로 들어가 온도 단위, 한 주의 시작 요일, 번호 환경설정 등을 정할 수 있다고 나옵니다. 지역 설정 메뉴가 보이지 않으면 Android 버전과 제조사별 메뉴 구성을 확인하세요.

자주 묻는 질문

Q. 모든 앱의 언어를 바꿀 수 있나요?

아닙니다. 개발자가 앱 언어 기능을 지원한 앱만 앱 목록에 나타납니다.

Q. 앱 언어를 바꿨는데 그대로예요.

앱을 다시 시작하고 네트워크 연결과 최신 버전 여부를 확인하세요. Google은 보조 언어를 추가한 뒤 다시 전환하는 방법도 안내합니다.

Q. 아이폰에서도 같은 메뉴가 있나요?

이 글은 Google의 Android 공식 안내를 기준으로 한 내용입니다. iPhone은 운영체제와 앱별 지원 방식이 다릅니다.
